# EVOLVE — Track Your Journey to a Better Self

A clean, no-sign-up habit tracker that lives right in your browser.


Live Here "https://ankitpareek-7.github.io/Evolve-Track-Your-Journey-To-Better-Self-Habit-Tracker/"

Evolve is a simple habit tracker I built to help myself (and anyone who finds it) stay consistent — without needing an app, an account, or a subscription. Open the page, add your habits, and start checking off days. That's it.

Everything is saved in your browser's local storage, so your data stays with you and never leaves your machine.



- **Monthly habit grid** — Each habit gets a row, each day gets a checkbox. Navigate between months with Prev / Next.
- **Weekly, Monthly & Consistency charts** — Visual progress bars so you can see how you're actually doing, not just how you *feel* you're doing.
- **Target Streak** — Set a custom goal (like 21 days) and track your progress toward it.
- **Daily To-Do List** — A quick checklist for today's tasks, with a progress bar at the bottom.
- **Rename, Add & Delete habits** — Manage your habits easily from the top of the grid card.
- **Dark theme with aqua-lime glow** — Because tracking habits at midnight shouldn't hurt your eyes.

## Tech

Just three files. No frameworks, no build step, no dependencies.

```
index.html   ← structure
style.css    ← styling (glassmorphism, gradients, glow effects)
script.js    ← all the logic (grid, charts, to-do, localStorage)
```

## Run it locally

Clone the repo and open `index.html` in your browser. Done.

```bash
git clone https://github.com/AnkitPareek-7/Evolve-Track-Your-Journey-To-Better-Self-Habit-Tracker.git
cd Evolve-Track-Your-Journey-To-Better-Self-Habit-Tracker
open index.html
```
